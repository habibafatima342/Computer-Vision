# Computer Vision Lab 01

## Overview
This repository contains a basic Computer Vision setup using Python and OpenCV.

## Files Description
- **`Files/images.py`**: A Python script that uses the OpenCV (`cv2`) library to load `car.jpg` from the `Images` folder, verify its dimensions, and display it in a popup window.
- **`Images/`**: Contains sample images used for testing:
  - `car.jpg`: An image of a car used for testing OpenCV loading and display functions.
  - `space.jpg`: An image of space for computer vision experiments.

## Requirements
- Python 3.x
- OpenCV (`pip install opencv-python`)
